# Spotify Clone
PROJECT LINK: https://shreya-pradhan22.github.io/Spotify-Clone/


A simple **Spotify Web Player Clone** built using **HTML, CSS, and JavaScript**.  
This project replicates the basic Spotify UI along with simple music player controls.

---

## Features
- Play / Pause songs
- Music progress bar
- Song list interface
- Spotify-style UI layout
- Player control icons

---

## Technologies Used
- HTML5
- CSS3
- JavaScript
